# 广州旅游

## 景点

### 越秀
- 越秀公园（爬山）

    - 10块
    - 墓室下层，需到官方号“南越王博物馆”免费预约，每天放当天和明天的票

    - 免费预约

- 北京路步行街

    - 3D裸眼大屏（打卡点）
